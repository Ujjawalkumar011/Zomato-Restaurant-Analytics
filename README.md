# 🍽️ Zomato Restaurant Analytics Dashboard

An end-to-end Data Analytics project using **SQL, PostgreSQL, Power BI, and Excel/CSV datasets** to analyze restaurant data and generate meaningful business insights.

## 📌 Project Overview

This project analyzes Zomato restaurant data to understand restaurant distribution across cities, cuisine popularity, customer ratings, food prices, and restaurant votes.

An interactive Power BI dashboard presents the results through KPI cards, charts, and filters.

## 🎯 Project Objectives

* Analyze restaurant distribution across cities.
* Compare restaurant ratings and customer votes.
* Identify popular cuisines and food items.
* Analyze food prices across different cities.
* Create an interactive Power BI dashboard.
* Practice SQL-based data analysis and visualization.

## 🛠️ Tools & Technologies

* **SQL** — Data querying and analysis
* **PostgreSQL** — Database management
* **Power BI** — Interactive dashboard and visualization
* **CSV / Excel** — Dataset storage and preparation

## 🚀 How to Use

1. Download or clone this repository.
2. Review the dataset in the `Dataset` folder.
3. Open the SQL file in PostgreSQL/pgAdmin and execute the required queries after configuring the database.
4. Open the Power BI `.pbix` file using Power BI Desktop.
5. Explore the dashboard using the available filters and visuals.
6. Refer to the `Documentation` folder for project details.
